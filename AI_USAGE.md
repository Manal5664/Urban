# AI-assisted development declaration

OpenAI ChatGPT and Codex are AI-assisted development tools used for this project.
AI-assisted work will be independently reviewed, tested, understood and modified
where necessary by the project team.

Final analytics, predictions, classifications, forecasts and recommendations will
be produced by our own implemented Big Data/Data Science/ML/application logic,
not an external generative-AI prediction API.

This declaration describes the intended development process; it does not claim
that any analytics, models, or application features have been implemented.
